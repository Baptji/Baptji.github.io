Squid Run

Boucles de course à pied, de jour comme de nuit

Squid Run propose des boucles de course au départ d'où vous êtes, à la distance choisie, en évitant les rues dangereuses et, de nuit, en restant dans les rues éclairées. Le parcours part ensuite sur l'Apple Watch, pour courir sans téléphone.

Assistance

Une question, une boucle étrange, une rue mal décrite ? Écrivez à baptiste.decobert@mailo.com.

Une erreur dans une rue (trottoir, éclairage, chemin) peut aussi se corriger directement sur OpenStreetMap : elle le sera pour tout le monde à la prochaine mise à jour des cartes.

Premium

La boucle est gratuite. L'abonnement Premium ajoute quatre formes de parcours : le papillon, la raquette, l'aller-retour et l'exploration du quartier. Il se résilie à tout moment dans les réglages de votre compte App Store.
